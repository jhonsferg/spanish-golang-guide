# Go 1.20 (febrero 2023)

Trae `errors.Join` (por fin agrupar varios errores sin inventar tu propio
tipo) y el debut de PGO (Profile-Guided Optimization).

## Cambios de lenguaje

- **Conversión slice → array**: ahora se puede escribir `[4]byte(x)` en vez
  de `*(*[4]byte)(x)`.
- Nuevas funciones en `unsafe`: `SliceData`, `String`, `StringData`.
- Especificación más precisa: structs y arrays se comparan campo a campo /
  elemento a elemento, en orden.
- `comparable` en genéricos ahora acepta tipos no estrictamente comparables
  en tiempo de compilación (p.ej. interfaces), delegando el chequeo a
  runtime.

## Runtime y garbage collector

- Reorganización de estructuras internas del GC: hasta 2% menos overhead de
  CPU y memoria.
- Nuevo paquete `runtime/coverage` para volcar perfiles de cobertura desde
  programas de larga duración.
- Comportamiento más consistente en la asistencia de goroutines al GC.

## Herramientas

- **cgo deshabilitado por defecto** en sistemas sin toolchain C
  (`CGO_ENABLED=0` pasa a ser el default en esos casos).
- Nuevas flags de `go`: `-C <dir>` (cambiar directorio antes de ejecutar),
  `-skip` (para test/generate), `-pgo` (profile-guided optimization),
  `-cover`.
- Soporte de build tags de arquitectura específicos (p.ej. `amd64.v2`).
- Se elimina `go build -i`, deprecada desde 1.16.
- **vet**: mejor detección de captura de variables de loop con
  `T.Parallel()`; nuevo diagnóstico para formatos de fecha incorrectos
  (`2006-02-01` vs `2006-01-02`).

## Librería estándar

**Manejo de errores**

- `errors.Join()`: agrupa múltiples errores en uno solo.
- `fmt.Errorf()` admite múltiples `%w` para envolver varios errores a la vez.
- `errors.Is()`/`errors.As()` actualizados para recorrer múltiples errores
  envueltos.

**Criptografía**

- Nuevo paquete `crypto/ecdh`: soporte explícito para ECDH en curvas NIST y
  Curve25519.
- `crypto/ed25519`: soporte para Ed25519ph y Ed25519ctx (con pre-hashing).
- `crypto/rsa`: backend más seguro para OAEP (15-45% más lento, a cambio de
  seguridad).

**HTTP**

- Nuevo `net/http.ResponseController`: acceso per-request a
  `SetReadDeadline`, `SetWriteDeadline`, etc.
- `WriteHeader()` soporta códigos `1xx`.
- `httputil.ReverseProxy`: nuevo hook `Rewrite` que reemplaza `Director`.

**Otras adiciones**

| Paquete | Cambio |
|---|---|
| `bytes`, `strings` | `CutPrefix()`, `CutSuffix()` |
| `context` | `WithCancelCause()`, `Cause()` |
| `math/rand` | Auto-seeding global; `Seed()` deprecado |
| `sync.Map` | `Swap()`, `CompareAndSwap()`, `CompareAndDelete()` |
| `time` | `DateTime`, `DateOnly`, `TimeOnly`; `Time.Compare()` |
| `path/filepath` | `IsLocal()` |

**Performance**: PGO (`-pgo`) mejora benchmarks 3-4%; velocidad de build
hasta 10% mejor que Go 1.19.
