# Go 1.21 (agosto 2023)

Una de las versiones más cargadas: `min`/`max`/`clear` como built-ins,
`log/slog` en la librería estándar, y los paquetes `slices`/`maps`/`cmp`
que hoy usarías en casi cualquier programa Go.

## Cambios de lenguaje

- Nuevas funciones built-in: **`min()`**, **`max()`** y **`clear()`**.
- Type inference mejorado: soporta funciones genéricas como argumentos,
  inferencia desde métodos de interfaces, y mejor manejo de constantes sin
  tipo.
- El orden de inicialización de paquetes queda especificado
  algorítmicamente de forma determinista.
- `panic(nil)` ahora produce `*runtime.PanicNilError` en vez de permitir un
  panic con valor nil.
- Preview de *loop variables* por iteración vía `GOEXPERIMENT=loopvar`
  (se vuelve comportamiento por defecto en Go 1.22).

## Runtime y garbage collector

- Stack traces muestran las primeras 50 y las últimas 50 frames en stacks
  muy profundos.
- Mejor uso de huge pages en Linux: hasta 50% menos memoria en heaps
  pequeños.
- Tuning del GC reduce hasta 40% la latencia de cola en algunas apps.
- Llamadas C→Go reutilizan el setup entre llamadas: de 1-3 µs a 100-200 ns.
- Nuevo `runtime.Pinner` para "fijar" memoria Go usada desde C.

## Herramientas

- **GODEBUG formalizado**: el comportamiento de compatibilidad se controla
  según la línea `go` de `go.mod`/`go.work`.
- `go 1.21.0` en `go.mod` impone una versión mínima estricta del toolchain.
- **Toolchain auto-switching**: el comando `go` descarga automáticamente la
  versión de Go que el módulo requiere.
- **PGO en producción** (era preview en 1.20): `-pgo=auto` por defecto si
  existe `default.pgo`.
- Build hasta 6% más rápido gracias a PGO aplicado al propio compilador.

## Librería estándar

**Nuevos paquetes — probablemente los más usados de esta lista**

- **`log/slog`**: logging estructurado con niveles, nativo en la librería
  estándar (ver [Capítulo 37](../05-produccion-y-herramientas/37-logging-y-observabilidad.md)).
- **`slices`**: operaciones genéricas sobre slices.
- **`maps`**: operaciones genéricas sobre maps.
- **`cmp`**: constraint `Ordered` y funciones `Less()`, `Compare()`.
- `testing/slogtest`: valida implementaciones de `slog.Handler`.

**Otros cambios**

| Paquete | Cambio |
|---|---|
| `context` | `WithoutCancel()`, `WithDeadlineCause()`, `WithTimeoutCause()`, `AfterFunc()` |
| `crypto/tls` | `SessionState` personalizable; `QUICConn` para QUIC 0-RTT |
| `crypto/sha256` | Instrucciones nativas amd64: 3-4x más rápido |
| `sync` | `OnceFunc()`, `OnceValue()`, `OnceValues()` para inicialización perezosa |
| `net` | Multipath TCP en Linux (opt-in) vía `SetMultipathTCP()` |
| `runtime/metrics` | Métricas de GC (heap vivo, GOGC, GOMEMLIMIT) ahora públicas |
| `errors` | Nuevo `ErrUnsupported` |

**Deprecaciones**: `crypto/elliptic.Curve` (usar `crypto/ecdh`),
`reflect.SliceHeader`/`StringHeader` (usar `unsafe.Slice`/`unsafe.String`).
