# Go 1.24 (febrero 2025)

Rediseña `map` por dentro (Swiss Tables), formaliza la gestión de
herramientas en `go.mod`, y añade `os.Root` para confinar operaciones de
filesystem a un directorio - una pieza clave si procesas archivos de
terceros.

## Cambios de lenguaje

- **Generic type aliases**: soporte completo - un alias puede estar
  parametrizado igual que un tipo definido. Desactivable con
  `GOEXPERIMENT=noaliastypeparams`.

## Runtime y garbage collector

- **Mapas reimplementados con Swiss Tables**: 2-3% menos overhead de CPU en
  promedio. Desactivable con `GOEXPERIMENT=noswissmap`.
- Nueva implementación de mutex interno del runtime
  (`GOEXPERIMENT=nospinbitmutex` para revertir) y asignación de memoria más
  eficiente para objetos pequeños.
- **`runtime.AddCleanup()`**: reemplaza a `SetFinalizer` con un modelo más
  flexible - permite múltiples cleanups por objeto sin crear falsos ciclos
  que impidan la liberación.

## Herramientas

- **Gestión de herramientas ejecutables**: directivas `tool` en `go.mod`
  reemplazan el patrón manual de `tools.go`. `go get -tool` las añade;
  `go install tool` instala todas las declaradas.
- `go run` y `go tool` cachean los ejecutables compilados.
- `go build -json` y `go test -json` para salida estructurada.
- Nueva variable `GOAUTH` para autenticación flexible con módulos privados.
- `go build` fija la versión del módulo en el binario a partir de tags VCS.
- **Cgo**: anotaciones `#cgo noescape` y `#cgo nocallback` para optimizar
  llamadas a C.
- **vet**: nuevo analizador `tests` (detecta nombres/firmas incorrectas en
  tests, benchmarks, examples); `printf` detecta formato no constante;
  `copylock` detecta `sync.Locker` copiado en loops `for` de tres cláusulas.

## Librería estándar

**Seguridad de filesystem**

- `os.Root` / `os.OpenRoot()`: abre un directorio y confina todas las
  operaciones subsecuentes dentro de él - previene *path traversal* al
  procesar archivos subidos por usuarios o extraídos de un archivo.

**Criptografía - nuevos paquetes**

- `crypto/mlkem`: ML-KEM-768/1024, cifrado post-cuántico (FIPS 203).
- `crypto/hkdf`, `crypto/pbkdf2`, `crypto/sha3` (SHA-3, SHAKE, cSHAKE).
- Módulo criptográfico compatible con **FIPS 140-3** (`GOFIPS140`,
  GODEBUG `fips140`).
- `crypto/tls`: soporte para Encrypted Client Hello (ECH) y post-cuántico
  `X25519MLKEM768` habilitado por defecto.

**Testing**

```go
func BenchmarkX(b *testing.B) {
    for b.Loop() { /* se ejecuta exactamente una vez por -count */ }
}
```

`T.Context()`/`B.Context()` (contexto cancelado tras el test) y
`T.Chdir()`/`B.Chdir()`.

**Otras adiciones**

| Paquete | Cambio |
|---|---|
| `weak` (nuevo) | Weak pointers, útil para caches y weak maps |
| `bytes`, `strings` | Iteradores: `Lines()`, `SplitSeq()`, `FieldsSeq()` |
| `encoding/json` | Tag `omitzero`; `UnmarshalTypeError.Field` incluye structs embebidos |
| `encoding` | Nuevas interfaces `TextAppender`, `BinaryAppender` |
| `sync.Map` | Reimplementado, mejor rendimiento con modificaciones concurrentes |
| `math/rand.Seed()` | Ya no tiene efecto |
