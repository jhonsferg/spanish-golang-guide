# Go 1.23 (agosto 2024)

El `range` deja de estar limitado a slices, maps, arrays, strings, channels
e ints: ahora también itera sobre **funciones**, abriendo la puerta a
iteradores personalizados en toda la librería estándar.

## Cambios de lenguaje

- **Range over functions**: `range` acepta funciones iteradoras de los tipos
  `func(func() bool)`, `func(func(K) bool)` y `func(func(K, V) bool)`.
- Preview de generic type aliases dentro de un mismo paquete, vía
  `GOEXPERIMENT=aliastypeparams` (llega completo en Go 1.24).

## Runtime y garbage collector

- `time.Timer` y `time.Ticker` ahora son elegibles para GC en cuanto no
  quedan referencias, sin esperar a `Stop()`.
- Los channels de timer pasan a ser *unbuffered* (antes tenían buffer de 1),
  y `Reset()`/`Stop()` garantizan no dejar valores obsoletos en el canal.
  Controlado por el GODEBUG `asynctimerchan` (activo solo en módulos con
  `go 1.23.0+` en `go.mod`).
- El compilador puede solapar slots de stack de variables locales cuyos
  rangos de vida no se superponen.
- Mensajes de panic indentados con tab para distinguirse del stack trace.

## Herramientas

- `go env -changed`: muestra solo la configuración distinta del valor por
  defecto.
- `go mod tidy -diff`: imprime los cambios como diff unificado sin tocar
  archivos.
- Nueva directiva `godebug` en `go.mod` y `go.work`.
- **vet**: nuevo analizador `stdversion`, detecta uso de símbolos
  demasiado nuevos para la versión de Go declarada en el archivo.
- **Linker**: `//go:linkname` hacia símbolos internos sin marcar queda
  prohibido por defecto (`-checklinkname=0` para desactivarlo).
- **Telemetría opt-in**: nuevo comando `go telemetry` para recolectar
  estadísticas de uso del toolchain (por defecto, local, sin envío de
  datos).

## Librería estándar

**Nuevos paquetes**

- `iter`: definiciones base para construir iteradores personalizados
  (`iter.Seq[V]`, `iter.Seq2[K, V]`).
- `unique`: canonicalización de valores (`Make[T]`, `Handle[T]`) — útil para
  *interning* de strings u otros valores comparables.
- `structs`: `HostLayout`, para describir layouts de struct compatibles con
  APIs de sistema.

**Iteradores en `slices` y `maps`**

```go
slices.All(s)      // itera (índice, valor)
slices.Values(s)    // itera valores
slices.Collect(seq)   // materializa un iterador en slice
maps.Keys(m)        // itera claves
maps.Insert(m, seq)   // inserta desde un iterador
```

**Otros cambios**

| Paquete | Cambio |
|---|---|
| `crypto/tls` | Encrypted Client Hello (ECH); `X25519Kyber768Draft00` por defecto |
| `net/http` | `Cookie.Quoted`, `Cookie.Partitioned`, `Request.Pattern` |
| `os` | Nuevo `CopyFS()`; Unix sockets en Windows |
| `path/filepath` | `Localize()` — convierte paths slash-separated al formato del SO |
| `sync/atomic` | `And()`, `Or()` bitwise |
| `sync.Map` | `Clear()` |
