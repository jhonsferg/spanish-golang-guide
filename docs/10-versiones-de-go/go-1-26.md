# Go 1.26 (febrero 2026)

El GC "Green Tea" pasa de experimento a **default**, `go fix` se convierte
en un modernizador serio de código, y los generics pierden una restricción
molesta: por fin pueden autorreferenciarse.

## Cambios de lenguaje

- **`new()` con expresiones**: acepta una expresión como operando,
  permitiendo especificar directamente el valor inicial:

  ```go
  age := new(yearsSince(bornDate))
  ```

- **Generics autorreferenciables**: se elimina la restricción que impedía
  que un tipo genérico se refiriera a sí mismo en su propia lista de
  parámetros de tipo:

  ```go
  type Adder[A Adder[A]] interface {
      Add(A) A
  }
  ```

## Runtime y garbage collector

- **GC "Green Tea" por defecto** (experimental desde Go 1.25): mejor
  localidad y escalabilidad de CPU; 10-40% menos overhead de GC, y un 10%
  adicional en CPUs modernas amd64 (Intel Ice Lake, AMD Zen 4+).
  Desactivable con `GOEXPERIMENT=nogreenteagc`.
- Llamadas cgo ~30% más rápidas en overhead base.
- **Randomización de la dirección base del heap** en plataformas de 64 bits,
  mejora de seguridad (`GOEXPERIMENT=norandomizedheapbase64` para
  desactivar).
- **Goroutine leak profile** (experimental): detecta goroutines bloqueadas
  permanentemente, vía `GOEXPERIMENT=goroutineleakprofile` y el endpoint
  `/debug/pprof/goroutineleak` (se estabiliza en Go 1.27).

## Herramientas

- **`go fix` renovado**: pasa a ser el hogar de "modernizers" — decenas de
  fixers automáticos construidos sobre el mismo framework de análisis que
  `go vet`. Soporta directivas `//go:fix inline` para migraciones de APIs.
- `go mod init` establece una versión de Go más conservadora en `go.mod`
  (Go 1.N → `go 1.(N-1).0`).
- Se elimina `cmd/doc`/`go tool doc` — usar `go doc`.
- **pprof**: la UI web por defecto pasa a ser el flame graph.
- **Compilador**: más slices pueden asignarse en el stack en vez del heap
  (`-gcflags=all=-d=variablemakehash=n` para revertir).
- **Linker (windows/arm64)**: soporte de internal linking para programas
  cgo.

## Librería estándar

**Nuevos paquetes**

- `crypto/hpke`: Hybrid Public Key Encryption (RFC 9180), con soporte
  post-cuántico.
- `simd/archsimd` (experimental, `GOEXPERIMENT=simd`): vectores SIMD
  tipados (`Int8x16`, `Float64x8`, etc.).
- `runtime/secret` (experimental): borrado seguro de secretos en memoria
  (Linux amd64/arm64).

**Cambio importante en criptografía**: los parámetros `io.Reader` de
aleatoriedad en `crypto/dsa`, `crypto/ecdh`, `crypto/ecdsa`,
`crypto/ed25519`, `crypto/rand` y `crypto/rsa` **se ignoran** — siempre se
usa la fuente criptográfica segura del sistema. Para tests deterministas,
usa `testing/cryptotest.SetGlobalRandom()`; `GODEBUG=cryptocustomrand=1`
restaura el comportamiento anterior si de verdad lo necesitas.

`crypto/tls`: los híbridos post-cuánticos (`SecP256r1MLKEM768`,
`SecP384r1MLKEM1024`) quedan habilitados por defecto.

**Otras adiciones**

| Paquete | Cambio |
|---|---|
| `errors` | `AsType()` genérico y type-safe |
| `io` | `ReadAll()` ~2x más rápido, ~50% menos memoria |
| `log/slog` | `NewMultiHandler()` |
| `net` | `Dialer.DialIP()/DialTCP()/DialUDP()/DialUnix()` |
| `reflect` | Iteradores `Type.Fields()`, `Type.Methods()`, `Value.Fields()` |
| `testing` | `T.ArtifactDir()` |
| `bytes` | `Buffer.Peek()` |

## Plataformas

- Último release en macOS 12 (Go 1.27 exige macOS 13+).
- Se elimina el puerto de 32 bits `windows/arm`.
- `linux/riscv64` gana soporte de race detector.
