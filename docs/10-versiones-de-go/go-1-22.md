# Go 1.22 (febrero 2024)

Arregla, por fin, el bug más citado de Go (la variable de loop compartida) y
moderniza el router de `net/http` con métodos y wildcards nativos.

## Cambios de lenguaje

- **Variables de loop por iteración**: cada vuelta del `for` crea variables
  nuevas en vez de reutilizar las mismas - elimina la clásica trampa de
  capturar `i` o `v` en una goroutine o closure dentro del loop.
- **`range` sobre enteros**: `for i := range 10 { ... }`.
- Preview de iteradores range-over-function vía `GOEXPERIMENT=rangefunc`
  (se vuelve estable en Go 1.23).

## Runtime y garbage collector

- Metadata de GC ubicada más cerca de los objetos: 1-3% mejor
  latencia/throughput y ~1% menos overhead de memoria.
- Cambio de alineación: los objetos ahora se alinean a 8 bytes (antes 16+).

## Herramientas

- `go work vendor` para soporte de `vendor` en workspaces.
- `go test -cover` reporta cobertura incluso para paquetes sin archivos de
  test.
- **vet**: nuevas advertencias para `append()` sin usar el resultado, para
  `defer time.Since(...)` (no tiene sentido diferido), y para pares
  inválidos en `log/slog`; actualizado a las nuevas semánticas de loop.
- **Trace**: UI renovada orientada a threads, con duración completa de
  syscalls.
- **Compilador**: PGO mejora 2-14% en programas representativos;
  devirtualización combinada con inlining.
- **Linker**: `-s` y `-w` con comportamiento consistente y desacoplado.

## Librería estándar

**`net/http` - routing mejorado (el cambio más visible de esta versión)**

```go
mux.HandleFunc("POST /items/create", createItem)
mux.HandleFunc("GET /items/{id}", getItem)       // Request.PathValue("id")
mux.HandleFunc("GET /files/{path...}", serveFile) // wildcard de sufijo
mux.HandleFunc("GET /exact/match/{$}", exactOnly) // match exacto, sin trailing
```

Precedencia automática por especificidad. `GODEBUG=httpmuxgo121=1` restaura
el comportamiento anterior si lo necesitas.

**`math/rand/v2`** (nuevo paquete): interfaz `Source` simplificada (solo
`Uint64()`), generadores `ChaCha8` y `PCG`, funciones idiomáticas `IntN`,
`Int32N`, `Uint32N` y la genérica `N[T]`.

**`go/version`** (nuevo): validación y comparación de strings de versión de
Go.

**Otros cambios**

| Paquete | Cambio |
|---|---|
| `slices` | Nuevo `Concat()`; `Delete`, `Compact`, etc. ahora zeroan elementos liberados |
| `cmp` | Nuevo `Or()` |
| `crypto/tls` | TLS 1.2 como mínimo por defecto en servidores |
| `database/sql` | Nuevo tipo genérico `Null[T]` |
| `os` | Windows: `ReadDir` en lotes (~30% más rápido) |
| `reflect` | `TypeFor[T]()`; `PtrTo` deprecado en favor de `PointerTo` |
| `net` | `TCPConn.WriteTo()` usa `splice(2)` en Linux |
