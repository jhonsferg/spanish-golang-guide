# Go 1.25 (agosto 2025)

Sin cambios de lenguaje, pero con dos mejoras muy prácticas para producción:
`GOMAXPROCS` que respeta los límites de cgroups (adiós a sintonizarlo a mano
en Kubernetes) y `sync.WaitGroup.Go` para dejar de escribir
`Add(1)`/`defer Done()` a mano.

## Cambios de lenguaje

- Ninguno que afecte a programas existentes. La especificación elimina la
  noción de "core types" a favor de prosa dedicada — un cambio editorial,
  no de comportamiento.

## Runtime y garbage collector

- **`GOMAXPROCS` consciente de contenedores**: en Linux, considera los
  límites de ancho de banda de CPU del cgroup y se reajusta si cambian en
  caliente. Desactivable con `GODEBUG=containermaxprocs=0` o
  `updatemaxprocs=0`.
- **GC "Green Tea"** (experimental, `GOEXPERIMENT=greenteagc`): mejora la
  localidad y escalabilidad de CPU; se espera 10-40% menos overhead de GC
  (pasa a ser el GC por defecto en Go 1.26).
- **Flight Recorder**: `runtime/trace.FlightRecorder` captura trazas en un
  buffer circular en memoria, útil para depurar eventos raros sin el
  overhead de tracing continuo.
- Un panic recuperado y re-lanzado (`recovered, repanicked`) ya no repite el
  mensaje completo en el output.
- VMA names en Linux: anota regiones de memoria con contexto (p.ej.
  `[anon: Go: heap]`), desactivable con `GODEBUG=decoratemappings=0`.

## Herramientas

- `go build -asan`: detección de memory leaks habilitada por defecto.
- Nueva directiva `ignore` en `go.mod` para excluir directorios.
- `go doc -http`: levanta un servidor de documentación local.
- `go version -m -json`: `BuildInfo` en formato JSON.
- **vet**: nuevo analizador `waitgroup` (detecta llamadas incorrectas a
  `sync.WaitGroup.Add`) y `hostport` (detecta mal uso de
  `fmt.Sprintf("%s:%d", host, port)` en vez de `net.JoinHostPort`).
- **Compilador**: corrección de un bug de nil-check introducido en Go 1.21
  que podía retrasar el chequeo incorrectamente; generación de debug info en
  **DWARF5**, reduciendo tamaño de binario y tiempo de linking.

## Librería estándar

**`testing/synctest`** (graduado de experimental): ejecuta tests dentro de
una "burbuja" con tiempo virtualizado — ideal para probar código con
timeouts, tickers o cancelación sin esperas reales.

```go
synctest.Test(t, func(t *testing.T) {
    // el tiempo dentro de esta burbuja es virtual
})
```

**`sync.WaitGroup.Go`**: crea y cuenta una goroutine en un solo paso.

```go
var wg sync.WaitGroup
wg.Go(func() { doWork() }) // equivalente a Add(1) + go func(){ defer Done(); ... }()
```

**`encoding/json/v2`** (experimental, `GOEXPERIMENT=jsonv2`): decoding
sustancialmente más rápido; ver también [Go 1.27](go-1-27.md), donde se
estabiliza.

**Otros cambios**

| Paquete | Cambio |
|---|---|
| `crypto` | `MessageSigner`, `SignMessage`; RSA 3x más rápido generando claves |
| `hash` | Nuevas interfaces `XOF` y `Cloner` |
| `net/http` | `CrossOriginProtection` (protección CSRF nativa) |
| `os` | `Root` gana `Chmod`, `Chown`, `Readlink`, `Symlink` |
| `reflect` | `TypeAssert` para conversiones sin allocaciones |
