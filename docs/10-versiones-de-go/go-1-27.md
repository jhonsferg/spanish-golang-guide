# Go 1.27 (agosto 2026) - la versión actual

Es la versión de Go usada para verificar todos los ejemplos de código de
esta guía (`go version` → `go1.27.0`). Trae métodos genéricos, la
estabilización de `encoding/json/v2` y un candidato serio a reemplazar
`encoding/json` en proyectos nuevos.

## Cambios de lenguaje

- **Métodos genéricos**: una declaración de método puede declarar sus
  propios parámetros de tipo, independientes de los del tipo receptor.
  Ejemplo real en la librería estándar:

  ```go
  func (*Rand) N[Int intType](n Int) Int // math/rand/v2
  ```

- **Struct literals con selectores**: las claves en un literal de struct
  pueden ser cualquier selector de campo válido, no solo el nombre de un
  campo de nivel superior - útil para inicializar campos embebidos
  directamente.
- **Inferencia de tipos de función generalizada**: se aplica de forma
  consistente en todo contexto donde una función genérica se asigna a una
  variable con un tipo de función compatible.

## Runtime y garbage collector

- **Goroutine leak profile** (estable, era experimental en Go 1.26): nuevo
  tipo de perfil `goroutineleak` en `runtime/pprof` y el endpoint
  `/debug/pprof/goroutineleak`, para detectar goroutines bloqueadas para
  siempre - el equivalente a un memory leak, pero de goroutines.
- Tracebacks incluyen las etiquetas (labels) de `runtime/pprof`
  (desactivable con `GODEBUG=tracebacklabels=0`).
- Asignación de memoria hasta 30% más rápida para objetos pequeños
  (menores a 80 bytes), a cambio de ~60 KB extra en el binario.
- Se elimina el GODEBUG `asynctimerchan`: los channels de `time.Timer`/
  `time.Ticker` son siempre síncronos (unbuffered) - el comportamiento que
  Go 1.23 introdujo como opcional ahora es el único.

## Herramientas

- **`go` command**: ya no soporta módulos servidos desde `bzr`; `go doc`
  soporta `paquete@version` y la opción `-ex` para listar ejemplos
  ejecutables; `go mod tidy` fusiona bloques `require` duplicados en
  módulos `go 1.27+`.
- **`go fix`**: nuevos modernizadores automáticos - `atomictypes`,
  `embedlit`, `slicesbackward`, `unsafefuncs`.
- **`go test`**: ejecuta el chequeo `stdversion` por defecto; nuevo campo
  `OutputType` en la salida JSON.
- **Trace**: el flag `-http` se restringe a localhost por defecto.
- **Compilador**: las directivas `//line` con nombres relativos se
  resuelven contra el directorio del archivo; closures obtienen nombres más
  simples y mejor deduplicación de instancias.

## Librería estándar

**`encoding/json/v2`** (estable, experimental desde Go 1.25): revisión
mayor de `encoding/json`, con `Marshal`/`Unmarshal` que aceptan `Options`
variádicas y comportamiento más estricto por defecto (rechaza UTF-8
inválido en vez de sustituirlo silenciosamente). Convive con el paquete
`json` clásico - no lo reemplaza automáticamente. Junto a él llega
`encoding/json/jsontext` para procesamiento sintáctico de bajo nivel
(`Encoder`, `Decoder`, `Token`, `Value`). Puede desactivarse con
`GOEXPERIMENT=nojsonv2` si necesitas volver atrás.

**Nuevos paquetes de criptografía post-cuántica**

- `crypto/mldsa`: firmas ML-DSA (FIPS 204), complementa al `crypto/mlkem`
  de Go 1.24.
- `crypto/tls` y `crypto/x509` ganan soporte ML-DSA end-to-end, incluyendo
  el key exchange `MLKEM1024`.

**Otros nuevos paquetes**

- `uuid`: generación y parseo de UUIDs en la librería estándar - ya no hace
  falta una dependencia externa solo para esto.
- `simd` (experimental, `GOEXPERIMENT=simd`): API SIMD portátil y agnóstica
  del tamaño del vector; `simd/archsimd` extiende soporte a arm64 y
  WebAssembly de 128 bits.

**Otras adiciones**

| Paquete | Cambio |
|---|---|
| `bytes`, `strings` | Nueva función `CutLast` |
| `database/sql` | Nueva función `ConvertAssign` |
| `math/big` | Método `Divide` con modos de redondeo explícitos |
| `net/http` | Negociación ALPN; drena automáticamente el body no leído; `MaxHeaderValueCount` |
| `unicode` | Actualizado de Unicode 15 a Unicode 17 |

## Cambios de compatibilidad a tener en cuenta

GODEBUG removidos por completo (ya no se pueden restaurar):
`asynctimerchan`, `tlsunsafeekm`, `tlsrsakex`, `tls3des`, `tls10server`,
`x509keypairleaf`, `gotypesalias`.

## Requisitos de plataforma

- **macOS**: requiere macOS 13 (Ventura) o posterior.
- **PowerPC 64-bit Linux**: genera binarios ELFv2 (requiere kernel 3.13+).
